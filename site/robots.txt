# v10.11 · relatorio.html e avaliar.html NÃO entram aqui, de propósito.
#
# Eles carregam nome de cliente, valor, fotos e, no caso do avaliar, o
# token na URL — e por isso ganharam <meta name="robots" content="noindex">.
# Bloquear o rastreio aqui impediria o Google de LER esse noindex, e a
# URL poderia acabar indexada só pelo endereço, sem conteúdo. É o mesmo
# raciocínio explicado logo abaixo para /perfil.html?slug=: quem controla
# indexação é a meta, e a meta só funciona se a página puder ser lida.

# v10.1 · a URL antiga do perfil NÃO entra aqui, de propósito.
#
# /perfil.html?slug=… continua respondendo 200 (já circula em WhatsApp
# e cartão de visita) e declara canonical para /p/…. Para consolidar as
# duas num endereço só, o Google PRECISA conseguir buscar a URL antiga
# e ler esse canonical. Um Disallow aqui o impediria de ler — e ele
# manteria as duas versões no índice, ou nenhuma.
#
# Bloquear duplicata no robots.txt é o erro clássico: robots.txt
# controla RASTREIO, não indexação. Quem controla indexação é o
# canonical e a meta robots, e as duas só funcionam se a página puder
# ser lida.
